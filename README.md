# The Feeding Gap — Prototype

Small single-page web prototype to demonstrate a serious classroom game about school lunch insecurity, teacher burden, and community action.

## How to run
1. Create a new GitHub repository (or use an existing one).
2. Add `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open `index.html` locally in your browser, or enable GitHub Pages on the repository (Settings → Pages → choose main branch).
4. Play the prototype. When the overlay appears after win/lose, close it to reset.

## Expand ideas
- Add real, cited facts and local resource links.
- Add sound and character portraits.
- Store high scores and community actions on a server.
- Make levels representing different districts with different funding levels.
